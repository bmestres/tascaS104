#AssignmentS104

## Level1

### Exercise1 - UnitaryTests with JUnit
A set of unitary tests that validate the correct behavior of BookManager class functionalities.

### Exercise2 - Parameterized test
Using JUnit for parameterized test to validate the behavior of a ID letter calculator. Validates 10 different cases.


### Exercise3- Exceptions control
Forcing an ArrayIndexOutOfBoundsException and using unitary test to validate the exceptions are thrown as expected.


## Level2 - AssertJ
A set of tests using AssertJ for validation of different behaviors. 

### Exercise 1 - Validate two equal object's value

### Exercise 2 - Validate same object reference

### Exercise 3 - Validate two arrays are equal

### Exercise 4 - Validate arrayList of Object
- Verifies list contains all intended objects in any order.
- Verifies one object has been added only once.
- Verifies the array doesn't contain a given object.

### Exercise 5 - Verify key exists in a Map

### Exercise 6 - Validate Index out of bounds exception thrown properly
